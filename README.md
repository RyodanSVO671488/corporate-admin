# Корпоративная админ-панель

Учебный проект на Java и Spring Boot. В нём можно управлять пользователями, назначать роли и настраивать права доступа.

## Что можно делать

- Входить под разными пользователями.
- Добавлять и редактировать пользователей, менять пароль и блокировать вход.
- Создавать роли и выбирать для них права.
- Смотреть журнал изменений пользователей и ролей.

## Технологии

Java 21, Spring Boot, Spring Security, Thymeleaf и Spring Data JPA.
Для обычного запуска используется база H2. Также есть настройки для PostgreSQL.

## Как запустить

Нужно установить JDK 21. Затем открыть папку проекта в PowerShell и выполнить:

```powershell
.\mvnw.cmd spring-boot:run
```

После запуска открыть [http://127.0.0.1:8080](http://127.0.0.1:8080).
При первом запуске Maven скачает зависимости, поэтому нужен интернет.

## Логины и пароли

Для локального запуска:

- `admin` / `AdminDemo2026!` — полный доступ.
- `manager` / `ManagerDemo2026!` — работа с пользователями без назначения ролей.
- `auditor` / `AuditorDemo2026!` — просмотр пользователей, ролей и журнала.

Эти пользователи создаются при первом запуске с пустой базой. Если поменять пароль в панели, при перезапуске он останется новым. Данные H2 сохраняются в папке `data`.

## Как устроен код

- `web` — контроллеры и формы.
- `service` — основные действия с пользователями и ролями.
- `service/policy` — отдельные правила проверки доступа.
- `domain` — классы пользователя, роли и записи журнала.
- `repository` — работа с базой.
- `security` — вход и проверка прав.
- `audit` — запись изменений в журнал.

HTML-страницы находятся в `src/main/resources/templates`.

## SOLID и паттерны

Обязанности разделены между контроллерами, сервисами, проверками и репозиториями. У проверок доступа есть общий интерфейс `AccessMutationPolicy`, поэтому новые правила можно добавлять отдельными классами.

Используются Strategy для проверок доступа, Observer для записи аудита, простая фабрика `UserFactory` для создания пользователя и Repository для работы с данными.
